# 🚀 SkillMirror AI

SkillMirror AI is an AI-powered career guidance platform that helps students explore suitable career paths based on their skills. It provides career recommendations, salary growth predictions, personalized learning roadmaps, and an AI career mentor for guidance.

## ✨ Features

- 🎯 AI Career Prediction
- 💰 Salary Growth Visualization
- 📚 Personalized Learning Roadmap
- 🤖 AI Career Mentor Chatbot
- 📊 Interactive Plotly Charts

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- AI/LLM Integration
